# Security and privacy

Keep the bridge on a trusted network or an authenticated private-network route.
Use scoped/revocable credentials and encrypted local pairing. Review access
before sharing the app or dashboard.

Before posting diagnostics, remove printer and AMS serials, access codes,
API keys, pairing material, local paths, personal hostnames, addresses, job
names and camera images. Synthetic reproductions are preferred.

Report sensitive vulnerabilities through GitHub's private vulnerability
reporting feature when available. If unavailable, open an issue requesting a
private channel without including the sensitive details. Rotate exposed
credentials promptly.

Automated scans complement manual review. Neither establishes the absence of
all personal data. Rewriting Git history does not remove copies held in forks,
clones, cached views, existing pull requests or previously downloaded artifacts.
GitHub Support may be needed for sensitive cached material.
