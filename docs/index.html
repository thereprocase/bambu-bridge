What the bridge provides

Browser workspace
Printer state, temperatures, camera, AMS information and job controls in a build-free web app.
Print-progress viewer
A WebGL view combines model geometry, toolpaths and the printer's reported progress.
Local integrations
HTTP and WebSocket interfaces let Home Assistant and other clients share the bridge connection.
Job checks
Container and filament-mapping checks run before submission. These checks complement the printer's own protections.

Install and configure

Start with a P1S, LAN-Only Mode and Developer Mode where offered, its access code, and a host running Python 3.12 or newer. The setup guide covers environment configuration, API authentication, printer registration and certificate trust.
