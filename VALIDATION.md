# Validation

Run `uv run pytest` at the root and `npm test -- --runInBand` in `mobile/`.
Run `npx tsc --noEmit`, `npm run lint`, and Android unit tests for app changes.

Automated results establish software behavior for the tested fixtures.
Qualification of printer commands additionally requires supervised tests for
each model/firmware/accessory combination. Keep unqualified controls withheld.

Use synthetic fixtures and redact device-specific evidence before publication.
